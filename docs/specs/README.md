# Microkernel Firmware Specification

This repository contains the complete specification set for the Microkernel Firmware and its UEFI shim.

## Structure

- architecture/ → Architecture-level specifications
- implementation/ → Implementation-level specifications
- compliance/ → UEFI compliance definitions
- security/ → Security & attack surface analysis
- tests/ → Test plans and validation strategy
- templates/ → Reusable specification templates

## How to Use

1. Start with architecture/00_system_overview.md
2. Define interfaces and execution model
3. Define UEFI shim objectives
4. Define compliance scope
5. Define security model
6. Attach test coverage to each section

All documents must:
- Be versioned
- Reference related documents
- Define traceability to requirements and tests
